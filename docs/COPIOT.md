# Copilot — контракты, флаги, стоимость и приватность

Документ описывает поверхности AI Career Copilot (v7.0): что именно делает
каждая кнопка, какие данные появляются в базе, сколько стоит действие и что
считается недоверенным вводом.

## 1. Граница AI-слоя

**Детерминированное ядро не выходит в сеть и не вызывает модель.** Fit-score,
аудит грейда, извлечение HR-контакта, upskill-радар и ATS-проверка считаются
локально и воспроизводимо. Это осознанное решение: собственный `GROWTH_PLAN.md`
запрещал LLM-зависимость для первого MVP, а LLM добавляет латентность,
стоимость и риск утечки персональных данных.

Модель подключается **только по явной кнопке** «🤖 Разобрать глубже (AI)» и
**только за отдельными флагами**. При любой ошибке (нет ключа, таймаут,
невалидный JSON, «выдуманный» навык) пользователь получает детерминированный
разбор — ответ не пропадает.

## 2. Поверхности

| Поверхность | Вход | Выход | Стоимость | Событие |
|---|---|---|---|---|
| Разбор вакансии | `job_hash` | fit-score, разбор грейда, HR-ссылка, кнопки | бесплатно | `copilot_fit_viewed` |
| Enrichment | внешняя ссылка вакансии | полный текст вакансии (кэш 14 дней) | бесплатно | `copilot_enrichment_viewed` |
| «Написать HR» | `job_hash` | deep-link `t.me/{hr}` | бесплатно | `copilot_hr_link_clicked` |
| «Сохранить такой поиск» | `job_hash` | saved search из совпавших навыков | бесплатно | `copilot_search_saved` |
| CV под вакансию | `job_hash` + резюме | PDF в чат, ATS-отчёт, кэш `file_id` | 1 кредит | `copilot_cv_built` / `copilot_cv_cached` |
| AI-разбор | `job_hash` | JSON-разбор вакансии | 1 кредит | `copilot_ai_viewed` / `copilot_ai_failed` |
| Пересылка вакансии | текст поста | тот же разбор, дедуп по `job_hash` | бесплатно | `copilot_forward_analyzed` |
| Трекер отклика | кнопка «Отклик отправлен» | напоминание через 7 дней | бесплатно | `copilot_application_marked` / `copilot_application_answered` |
| `/upskill` | база вакансий | покрытие стеком, дефицит навыков | бесплатно | `copilot_upskill_viewed` |
| Mini App | подпись `initData` | fit, CV, сохранённые поиски | как в боте | `copilot_webapp_*` |

## 3. Кредиты

- Суточный бесплатный лимит: `COPILOT_FREE_PER_DAY` (по умолчанию 3) — начисляется
  один раз в сутки, идемпотентно (`free_granted_on IS DISTINCT FROM CURRENT_DATE`).
- Реферальный бонус: `COPILOT_REFERRAL_BONUS` (по умолчанию 5) — начисляется
  пригласившему за принятый инвайт.
- Баланс материализован в `growth_copilot_credits` с `CHECK (balance >= 0)`;
  списание — одним `UPDATE ... WHERE balance >= amount`, то есть атомарно.
- Аудит-лог: `growth_copilot_credit_events` (причина, дельта, ref).
- Глобальный суточный потолок LLM-вызовов: `COPILOT_LLM_DAILY_BUDGET`
  (по умолчанию 200) — считается по событиям `llm_call` за сутки.
- Бесплатный детерминированный разбор кредитов не списывает никогда.

## 4. Флаги

Все флаги — в `.env.example.txt` с комментариями. Новые функции по умолчанию
**выключены**.

```env
COPILOT_ENABLED=false               # базовый переключатель Copilot
COPILOT_ENRICH_ENABLED=false        # догрузка полного текста вакансии
COPILOT_PDF_ENABLED=false            # сборка CV под вакансию
COPILOT_FORWARD_ENABLED=false        # разбор пересланной вакансии
COPILOT_OUTCOME_ENABLED=false        # трекер откликов и напоминание
COPILOT_UPSKILL_ENABLED=false        # /upskill-радар
COPILOT_WEBAPP_ENABLED=false         # Mini App (нужен COPILOT_WEBAPP_URL)
COPILOT_LLM_ENABLED=false            # LLM-слой (нужен COPILOT_LLM_API_KEY)
COPILOT_FREE_PER_DAY=3
COPILOT_REFERRAL_BONUS=5
COPILOT_LLM_DAILY_BUDGET=200
COPILOT_LLM_API_KEY=                 # только в секретах окружения
COPILOT_LLM_BASE_URL=https://api.openai.com/v1
COPILOT_LLM_MODEL=gpt-4o-mini
COPILOT_LLM_TIMEOUT=15
COPILOT_LLM_MAX_TOKENS=900
COPILOT_LLM_CACHE_HOURS=12
COPILOT_LLM_SEND_RESUME=false       # по умолчанию резюме в модель не уходит
COPILOT_FOLLOWUP_DAYS=7
COPILOT_UPSKILL_DAYS=30
COPILOT_WEBAPP_URL=                  # публичный URL Mini App
```

## 5. Данные в базе

Все таблицы — в Supabase Postgres, префикс `growth_`, RLS включён, `anon` и
`authenticated` не имеют DML-прав.

| Таблица | Содержимое | TTL |
|---|---|---|
| `growth_copilot_profiles` | профиль пользователя: навыки, категории, грейд | 90 дней |
| `growth_copilot_evaluations` | fit-оценка по паре (пользователь, вакансия), `llm_used`, `model` | 90 дней |
| `growth_copilot_grade_audits` | аудит грейда вакансии (общий, не персональный) | 45 дней |
| `growth_copilot_enrichments` | кэш полного текста вакансии | 14 дней |
| `growth_copilot_documents` | `file_id` готового CV, хэш вакансии, fit-score | 90 дней |
| `growth_copilot_credits` | материализованный баланс кредитов | бессрочно |
| `growth_copilot_credit_events` | лог списаний и начислений | 180 дней |
| `growth_copilot_ai_reports` | кэш AI-ответов (без резюме) | 14 дней |
| `growth_copilot_forwarded_jobs` | пересланные вакансии (публичный текст) | 30 дней |
| `growth_copilot_applications` | трекер откликов: хэш, компания, стадия | 180 дней |
| `growth_copilot_rate_limits` | счётчик запросов Mini App | бессрочно |

**Чего в базе нет:** текста и байтов резюме, имён файлов резюме, содержимого
`initData`, ключей провайдера и токена бота.

## 6. Приватность

1. **Резюме живёт только в памяти одного запроса.** Файл разбирается
   (`pypdf` / `python-docx`), из него берутся навыки и контакты, дальше в БД
   попадает только `file_id` уже собранного PDF.
2. **AI получает минимум.** По умолчанию в модель уходят текст вакансии
   (с вырезанными инструкциями и отредактированными контактами) и навыки
   профиля. Отправка резюме включается только флагом
   `COPILOT_LLM_SEND_RESUME=true`.
3. **Ответ, построенный с резюме, не сохраняется.** В `growth_copilot_ai_reports`
   попадает только признак `used_resume`, без текста ответа.
4. **События аналитики не содержат персональных данных**: только хэш вакансии,
   счётчики и коды ошибок.
5. **Публикация в канал** по-прежнему только из Vercel production
   (`publication_authority.py`). Copilot в канал ничего не пишет.

## 7. Недоверенный ввод

Текст вакансии — это данные, а не инструкции. Перед любым вызовом модели он
проходит через `copilot/security.py`:

- вырезаются инструкции («ignore all previous instructions», «забудь все
  предыдущие инструкции», «you are now …», «print your prompt» и т. п.);
- редактируются контакты (e-mail, телефон, `@handle`);
- текст оборачивается в `<untrusted_job_post>` с явным указанием, что это данные;
- проверяется, не «приписала» ли модель пользователю навык, которого нет в
  профиле (ownership-формулировки рядом с отсутствующим навыком) — при нарушении
  ответ отбрасывается и показывается детерминированный разбор.

Подробнее — в [`../SECURITY.md`](../SECURITY.md).

## 8. Mini App: контракт API

`POST /api/copilot` и `POST /api/copilot/pdf`, тело — JSON, обязательное поле
`init_data` (подпись Telegram).

| Код | Условие | Сообщение |
|---|---|---|
| 200 | всё хорошо | — |
| 400 | неверное тело, нет вакансии, нечитаемое резюме | «Не удалось разобрать запрос…» |
| 401 | подпись не совпала или `auth_date` старше 24 ч | «Сессия недействительна. Открой приложение заново.» |
| 402 | кончились кредиты | «Бесплатные сборки на сегодня закончились…» |
| 404 | вакансия не найдена | «Вакансия не найдена.» |
| 413 | файл больше 2.5 МБ | «Файл слишком большой.» |
| 429 | больше 10 запросов за 10 минут | «Слишком много запросов. Подожди немного.» |
| 503 | рантайм недоступен | «Сервис временно недоступен. Попробуй позже.» |

Rate-limit считается в `growth_copilot_rate_limits` по `user_id`. Ответ
содержит только данные подписанного пользователя; публичная проекция
`growth-proxy/public-jobs` для персональных данных не используется.

## 9. Метрики

`/stats_growth` (админ) показывает блок Copilot за окно в days:

- разборы (канал, пересылка, Mini App);
- сохранённые поиски и конверсию «разбор → поиск»;
- собранные CV и выдачи из кэша;
- переходы к HR и просмотры upskill-радара;
- отмеченные и закрытые отклики;
- ответы LLM и доля откатов на детерминированный отчёт.

Источник — `growth_events`, запрос один с группировкой по имени события.
